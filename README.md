# KindLink

KindLink — веб-платформа, которая объединяет волонтёров и организации с добрыми инициативами.

## Возможности первой версии

- Публичный каталог опубликованных волонтёрских проектов.
- Поиск по названию, описанию и городу; фильтр по категории.
- Регистрация и вход через Supabase Auth.
- Два типа аккаунтов: волонтёр и организация.
- Волонтёры отправляют одну заявку на каждый проект и видят её статус в личном кабинете.
- Организации создают проекты, просматривают заявки и принимают или отклоняют их.
- Непроверенные организации могут сохранять проекты как черновики. Публикация доступна после проверки администратором.
- Row Level Security (RLS) ограничивает доступ к данным на уровне базы.

## 1. Создай проект Supabase

1. Открой [supabase.com](https://supabase.com/) и создай новый проект.
2. В панели проекта открой **SQL Editor → New query**.
3. Скопируй весь текст из `supabase/schema.sql`, вставь в редактор и нажми **Run**.
4. Открой **Project Settings → API** (или раздел API Keys в новой панели).
5. Скопируй **Project URL** и публичный **anon / publishable key**.

## 2. Подключи сайт к Supabase

Открой `js/config.js` и замени значения:

```js
window.KINDLINK_CONFIG = {
  supabaseUrl: "https://YOUR-PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY"
};
```

Используй только публичный anon/publishable key. **Никогда не вставляй `service_role` / secret key в HTML, JavaScript или репозиторий GitHub.** Защита данных обеспечивается RLS-политиками базы.

## 3. Настрой регистрацию

В Supabase открой **Authentication → URL Configuration** и добавь URL сайта в Site URL и Redirect URLs. Для локального теста можно добавить адрес Live Server, например `http://127.0.0.1:5500/**`.

Для первого запуска можно оставить подтверждение email включённым. После регистрации пользователь получит письмо и должен подтвердить адрес, прежде чем войти (если включено подтверждение email в настройках Auth).

## 4. Запусти локально

Открой папку `kindlink` в Visual Studio Code и запусти `index.html` через расширение **Live Server**. Не открывай файл двойным нажатием: локальный сервер удобнее для работы с Auth и URL-переадресацией.

Без настроенного Supabase сайт показывает демонстрационные карточки. Регистрация, заявки и создание проектов становятся активными после подключения базы.

## 5. Проверь организацию и разреши публикацию

По умолчанию профиль организации создаётся с `is_verified = false`. Это сделано специально: открытая регистрация сама по себе не подтверждает, что организация настоящая.

После проверки организации администратор может включить публикацию вручную через Supabase SQL Editor. Сначала найди пользователя в **Authentication → Users**, затем выполни запрос, подставив его UUID:

```sql
update public.profiles
set is_verified = true
where id = 'UUID_ПРОВЕРЕННОЙ_ОРГАНИЗАЦИИ'
  and role = 'organization';
```

Не выдавай эту возможность обычным пользователям сайта. В этой версии нет отдельной админ-панели и автоматической проверки документов.

## 6. Публикация сайта

Можно разместить статические файлы на GitHub Pages, Netlify или Vercel. Загрузи содержимое папки `kindlink` в репозиторий/проект хостинга, затем укажи URL опубликованного сайта в Supabase **Authentication → URL Configuration**.

## Важные замечания перед публичным запуском

Это рабочая стартовая версия, но не готовая к запуску крупная социальная платформа. Перед приглашением реальных пользователей добавь:

- страницу правил сообщества, политику конфиденциальности и способ связи с администрацией;
- админ-панель для проверки организаций, жалоб и сомнительных публикаций;
- безопасный процесс участия несовершеннолетних: проекты с офлайн-встречами должны иметь ответственного взрослого/координатора, понятные условия и безопасное место проведения;
- уведомления о заявках, восстановление пароля и возможность удаления аккаунта;
- тестирование RLS на отдельных аккаунтах волонтёра, организации и гостя.

Не проси волонтёров публиковать домашний адрес, личные документы, пароли, банковские данные или другую лишнюю личную информацию. В первой версии контактные данные волонтёров не показываются публично.
